Student Performance Analytics 📊

An exploratory data analysis project investigating factors associated with students’ academic performance using Python and the UCI Student Performance dataset.

📌 Project Overview

This project explores student performance patterns through data cleaning, descriptive statistics, visualisations, group comparisons, and correlation analysis.

The objective is to investigate how factors such as study time, previous academic failures, and school absences relate to students’ final grades.

📂 Dataset

* Source: UCI Machine Learning Repository – Student Performance
* Dataset analysed: student-por.csv
* Subject: Portuguese language
* Total observations: 649 students
* Target variable: G3 (final grade)

🛠️ Tools & Technologies

* Python
* pandas
* matplotlib
* Deepnote

🔍 Research Questions

This analysis explores four main questions:

1. How is reported study time associated with students’ final grades?
2. How do previous academic failures relate to final performance?
3. What patterns can be observed between school absences and final grades?
4. What insights can descriptive statistics and visualisations reveal about student performance?

⚙️ Project Workflow

1. Imported and inspected the dataset.
2. Examined data types and checked for missing values.
3. Calculated descriptive statistics.
4. Compared average final grades across study-time and previous-failure groups.
5. Created visualisations to identify patterns.
6. Examined correlations between selected variables and final grades.
7. Interpreted the findings while considering the limitations of observational data.

📈 Key Findings

The exploratory analysis produced the following results:

* 649 student records were analysed, with no missing values found in the loaded dataset.
* The average final Portuguese grade (G3) was approximately 11.91 out of 20.
* Study time and final grade showed a positive correlation of approximately 0.250.
* Previous academic failures and final grade showed a negative correlation of approximately -0.393.

These findings indicate associations within the dataset. They do not establish cause-and-effect relationships.

⚠️ Limitations

* The analysis is observational; correlation does not imply causation.
* The project focuses on Portuguese-language performance, not mathematics.
* The dataset represents a particular student population and may not generalise to every educational setting.
* The findings should be interpreted as exploratory insights rather than definitive conclusions.
